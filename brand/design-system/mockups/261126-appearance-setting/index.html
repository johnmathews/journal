Appearance: accent colour

How should the accent-colour setting look, and which colours should it offer? It is a new “Appearance” tab in Settings. Violet stays the default and stays exactly as it is today; the icon stays green whatever is picked.

Click any colour: the pane recolours the way the app will (tab underline, active sidebar item, button, link). The choice is saved to the account, so it follows the user to every device.

A. A row of swatches

Option A

Compact: one circle per colour with its name underneath. The page itself is the preview, since it recolours as soon as a colour is picked.

B. Cards with a sample

Option B

A radio card per colour, each with a small button drawn in it, so the colours can be compared before picking one. Takes more room.

Contrast of each colour

Measured for the pairings the views use. Violet is today’s scale, unchanged, so it keeps today’s two small misses (left as is, by choice). The new colours draw focus outlines and checkboxes in dark mode one step lighter (their 400, the “edge”), because their 500 is too dark on the dark panel; violet keeps its 500.
