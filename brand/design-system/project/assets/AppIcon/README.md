# App icon

Journal's mark is a ruled page with a pen writing its last line, drawn white on a rounded tile in the user's accent colour. There is one master per accent: `journal-icon-<accent>.svg` for the favicon and home screen, and `journal-icon-maskable-<accent>.svg` with the glyph scaled into the safe zone for Android's masked icons.

- Use the violet master wherever the user's accent is unknown (docs, the default favicon).
- Never recolour the glyph: it is always white. Never put the mark on a ground of its own accent without its tile.
- In the app, `AppLogo.vue` draws the mark with the tile in `accent-500`, so it follows Settings → Appearance. The sidebar shows it beside "JOURNAL INSIGHTS TOOL", and alone when the sidebar collapses.
- These files are generated by `npm run icon:gen` in `webapp/` from `src/brand/app-icon.json`. Don't edit them by hand: `npm run icon:check` fails in CI if they drift.
